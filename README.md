# Kas RT 01 / RW 01

Aplikasi pencatatan keuangan RT 01 / RW 01, Dukuh Gudang, Desa Surorejan, Kecamatan Puring, Kabupaten Kebumen.

## Arsitektur

- **Frontend:** GitHub Pages (HTML/CSS/JavaScript)
- **Backend:** Google Apps Script Web App
- **Database:** Google Sheets
- **Storage:** Google Drive
- **Reports:** PDF generated by backend

### Alur data

```text
GitHub Pages
    │
    │ HTTPS API
    ▼
Google Apps Script Web App
    │
    ▼
Google Sheets / Google Drive
```

Frontend GitHub Pages tidak menggunakan `google.script.run`. Semua komunikasi database dilakukan melalui API pada Web App Apps Script.

## Struktur frontend

```text
index.html
css/style.css
js/config.js
js/api.js
js/app.js
js/whatsapp.js
```

## Backend

Source backend yang menjadi acuan deployment disimpan di:

```text
backend/Code.gs
```

Folder `apps-script/` merupakan snapshot/legacy dan tidak menjadi source utama deployment.

## Setup backend

1. Buka Google Apps Script baru atau project backend yang sedang dipakai.
2. Salin `backend/Code.gs` ke project Apps Script.
3. Pastikan `DB_ID` mengarah ke spreadsheet database yang benar.
4. Jalankan `setupApp()` satu kali dan selesaikan authorization.
5. Deploy sebagai **Web app**.
6. Pilih **Execute as: Me**.
7. Berikan akses Web App sesuai kebutuhan aplikasi.
8. Salin URL `/exec`.
9. Isi URL tersebut ke `js/config.js`.
10. Push perubahan ke branch/repository GitHub.

## API

### Public

- `GET ?action=initialData`
- `GET ?action=diagnostic`
- `GET ?action=reportSummary`

### Write / admin

- `POST action=createTransaction`
- `POST action=updateTransaction`
- `POST action=cancelTransaction`
- `POST action=updateConfig`
- `POST action=changePassword`
- `POST action=getWarga`
- `POST action=saveWarga`
- `POST action=deleteWarga`
- `POST action=uploadAttachment`
- `POST action=createReportPdf`

## WhatsApp

Frontend menyediakan:

- **Bagikan WhatsApp** untuk membuka WhatsApp dengan laporan kas otomatis.
- **Salin Pesan** untuk menyalin laporan ke clipboard.

Tidak ada WhatsApp API secret di repository.

## Keamanan

- Password admin tidak boleh disimpan di frontend/GitHub.
- Jangan menaruh API secret atau token permanen di `js/config.js`.
- Backend menjadi sumber kebenaran saldo dan transaksi.
- Edit dan pembatalan transaksi membutuhkan otorisasi admin serta alasan.
- Histori perubahan tetap dicatat pada `AUDIT_LOG`.
- Jangan menghapus deployment backend lama sampai deployment baru berhasil diuji.

## Git workflow

```text
refactor/github-gas-api
```

Setelah pengujian selesai, branch dapat di-merge ke `main`.
